# Материалы для анализа AI-текста

Эта папка содержит 5 специализированных файлов контекста для обнаружения AI-маркеров в текстах.

## Назначение файлов

### 01 - Структурные паттерны.md
**Что обнаруживает:**
- Чрезмерное использование тире (em dash)
- Триколоны (правило троек)
- Отрицательные параллелизмы
- Ложные диапазоны "от-до"
- Формулу "X с Y и Z"

**Когда использовать:** Когда нужно проверить структуру предложений и общую организацию текста.

---

### 02 - Слова-маркеры.md
**Что обнаруживает:**
- AI-словарь (delve, tapestry, intricate, showcase, underscore...)
- Характерные имена персонажей (Elara Voss, Kael)
- Культурные заимствования
- Связующие слова (Additionally, Furthermore)

**Когда использовать:** Для быстрой проверки на наличие характерных слов AI.

---

### 03 - Атмосферные клише.md
**Что обнаруживает:**
- Одержимость призраками и призрачностью
- Описания "тихого" и "гудящего"
- Метафоры ткани и гобеленов
- Путешествия в неожиданных местах
- Неправильное использование сенсорного языка

**Когда использовать:** Когда нужно оценить общую атмосферу и образность текста.

---

### 04 - Содержательные паттерны.md
**Что обнаруживает:**
- Преувеличение значимости
- Рекламный язык
- Расплывчатые атрибуции
- Поверхностные анализы
- Схематичные выводы о проблемах

**Когда использовать:** Для анализа содержания и смысловых паттернов.

---

### 05 - Грамматические тики.md
**Что обнаруживает:**
- Элегантную вариацию (избегание повторов)
- Избегание is/are
- Конструкции с причастиями
- Избыточные связки

**Когда использовать:** Для проверки грамматических особенностей и синтаксиса.

---

## Как использовать эти файлы

### Базовый анализ (все категории)

Подключите все 5 файлов:

```
@Материалы/01 - Структурные паттерны.md 
@Материалы/02 - Слова-маркеры.md 
@Материалы/03 - Атмосферные клише.md 
@Материалы/04 - Содержательные паттерны.md 
@Материалы/05 - Грамматические тики.md

Проанализируй этот текст на наличие AI-маркеров:

[ваш текст]
```

### Быстрая проверка (только слова-маркеры)

```
@Материалы/02 - Слова-маркеры.md 

Проверь, есть ли в этом тексте слова-маркеры AI:

[ваш текст]
```

### Целевой анализ (выборочные категории)

Например, только структура и атмосфера:

```
@Материалы/01 - Структурные паттерны.md 
@Материалы/03 - Атмосферные клише.md 

Проанализируй структуру и атмосферу этого текста:

[ваш текст]
```

## Рекомендации

### Для экономии токенов
- Начинайте с одного файла (обычно `02 - Слова-маркеры.md`)
- Добавляйте другие файлы, если нужен более глубокий анализ

### Для максимальной точности
- Подключайте все 5 файлов сразу
- Учитывайте, что это увеличит стоимость запроса

### Для редактуры
- Сначала проанализируйте с помощью файлов
- Затем попросите агента исправить выявленные проблемы
- Проверьте результат снова

## Структура файлов

Каждый файл содержит:

1. **Описание роли** — настройка экспертизы агента
2. **Ключевые паттерны** — что искать
3. **Примеры** — как выглядят паттерны в реальных текстах
4. **Техники обнаружения** — как проверять

## Примеры использования

### Пример 1: Полный анализ

**Запрос:**
```
@Материалы/01 - Структурные паттерны.md 
@Материалы/02 - Слова-маркеры.md 
@Материалы/03 - Атмосферные клише.md 
@Материалы/04 - Содержательные паттерны.md 
@Материалы/05 - Грамматические тики.md

Проанализируй этот текст по всем категориям AI-маркеров. 
Для каждой найденной проблемы приведи конкретный пример из текста.

[текст]
```

**Результат:** Детальный отчёт с примерами по каждой категории.

### Пример 2: Анализ + редактура

**Запрос 1:**
```
@Материалы/02 - Слова-маркеры.md 
@Материалы/01 - Структурные паттерны.md 

Найди все слова-маркеры и структурные паттерны в этом тексте:

[текст]
```

**Запрос 2:**
```
Теперь отредактируй текст, удалив все найденные AI-маркеры. 
Сохрани смысл, но сделай текст более естественным.
```

### Пример 3: Проверка своего текста

```
@Материалы/02 - Слова-маркеры.md 

Я написал этот текст сам. Проверь, нет ли в нём случайных AI-маркеров, 
которые делают его похожим на AI-текст:

[мой текст]
```
