## Топ-10 структурных паттернов

Грамматические конструкции, характерные для AI:

### 1. Конструкция "не X — это Y" с тире

```
❌ "Это не просто технология — это революция"
✅ "Это больше, чем технология"
```

### 2. Правило троек (триколоны)

```
❌ "global experts, innovative thinkers, and industry leaders"
✅ "experts and industry leaders"
```

### 3. "Нет X. Нет Y. Только Z."

```
❌ "Ни семьи. Ни звонков. Только тишина."
✅ "Никто не пришёл — ни семья, ни знакомые."
```

### 4. "X с Y и Z" (для сарказма)

```
❌ "тролль с Reddit с Wi-Fi и миллиардами"
✅ "интернет-тролль с миллиардами долларов"
```

### 5. Отрицательные параллелизмы

```
❌ "not only ... but also..."
❌ "It's not just about X, it's about Y"
✅ Прямое утверждение без отрицания
```

### 6. Избегание is/are → serves as/marks

```
❌ "Gallery serves as exhibition space"
✅ "Gallery is an exhibition space"
```

```
❌ "The building boasts four galleries"
✅ "The building has four galleries"
```

### 7. Ложные диапазоны "от... до..."

```
❌ "From the Big Bang to cosmic web" (нет шкалы)
✅ "From the Big Bang to present day" (есть шкала)
```

### 8. Элегантная вариация (избегание повторов)

```
❌ В тексте: "artists", "non-conformist artists", "like-minded artists", "avant-garde artists"
✅ Нормальное повторение: "artists" несколько раз
```

### 9. Риторические вопросы

```
❌ "And you know what? This is amazing."
✅ "This is amazing."
```

### 10. Встроенные заголовки в списках

```
❌ - **Key Point:** Important information here
✅ - Important information here
```

## Топ-5 атмосферных маркеров

Образные клише, которые AI использует повсеместно:

### 1. Призраки и призрачность

- **ghost** / **phantom** / **spectral**
- **shadow** (в переносном смысле)
- **echo** (метафора)
- **memory** (как абстракция)
- **liminal** (пограничный)

```
❌ "ghostly echo of innovation"
✅ "signs of innovation"
```

### 2. Тишина и гудение

- **quiet** (чрезмерное использование)
- **hum** / **humming**
- **whisper** (метафора)
- **softly** / **gentle**
- **murmur**

```
❌ "in the quiet hum of our digital era"
✅ "in our digital era"
```

### 3. Ткачество

- **woven into** / **interwoven**
- **tapestry** (метафора)
- **fabric of** (абстракция)
- **thread** (в переносном смысле)

```
❌ "woven into the fabric of society"
✅ "part of society"
```

### 4. Путешествия

- **journey** (метафора)
- **explore** (без реального исследования)
- **delve into** (см. топ-слова)
- **venture into**
- **navigate**
- **embark on**

```
❌ "journey through data"
✅ "analysis of data"
```

### 5. Неправильный сенсорный язык

Применение физических ощущений к абстракциям:

```
❌ "Thursday tastes like almost-Friday"
❌ "grief has a taste"
❌ "the smell of dreams"
✅ Конкретные сенсорные описания реальных объектов
```

## Шкала вероятности AI-генерации

### Подсчёт маркеров

**На 500 слов текста:**

- **0-2 маркера** → 0-20% — вероятно человеческий текст
- **3-5 маркеров** → 21-40% — низкая вероятность AI
- **6-10 маркеров** → 41-60% — средняя вероятность AI
- **11-15 маркеров** → 61-80% — высокая вероятность AI
- **16+ маркеров** → 81-100% — очень высокая вероятность AI

### Особые случаи

**Красные флаги (почти гарантированно AI):**
- 3+ триколона в тексте на 100 слов
- "tapestry" + "delve" + "pivotal" в одном абзаце
- "quiet" использовано 3+ раза на 500 слов
- 5+ слов из топ-20 в одном абзаце

## Примеры использования справочника

### Пример 1: Быстрая оценка текста

**Текст (50 слов):**
```
The evolving landscape of remote work has transformed into a vibrant tapestry of opportunities. This dynamic shift is not just about technology—it's about fostering connections. Companies are delving into new ways to cultivate work-life balance.
```

**Подсчёт маркеров:**
- Структура: 1 (тире "не X — это Y")
- Словарь: 6 (evolving landscape, vibrant, tapestry, dynamic, fostering, delving, cultivate)
- Атмосфера: 1 (tapestry)
- Содержание: 2 (vibrant, dynamic)

**Итого:** 10 маркеров на 50 слов = 100 маркеров на 500 слов

**Вероятность AI:** 95-100%

### Пример 2: Сравнение текстов

**Текст A (AI):**
```
The conference brought together global experts, innovative thinkers, and industry leaders to explore the evolving landscape.
```
Маркеры: триколон + 3 AI-слова = 4 маркера на 17 слов

**Текст B (человек):**
```
The conference brought together experts to discuss AI challenges.
```
Маркеры: 0
