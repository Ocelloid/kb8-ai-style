## D.1 Текст с ОЧЕНЬ ВЫСОКОЙ концентрацией маркеров (95%)

### The Future of Remote Work

```
The evolving landscape of remote work has transformed into a vibrant tapestry of opportunities and challenges. This shift is not just about technology—it's about fostering human connections in a digital age. From innovative collaboration tools to flexible work arrangements, companies are delving into new ways to maintain productivity while cultivating work-life balance.

The journey from traditional offices to distributed teams marks a pivotal moment in how we think about work. As we move forward, understanding the intricate interplay between technology and human needs remains crucial for harnessing remote work's transformative potential. This dynamic environment showcases the enduring commitment of organizations to adapt and thrive in an increasingly digital world.
```

### Анализ маркеров

**Структурные (2):**
- "not just about X—it's about Y" (тире + противопоставление)
- "From... to..." (ложный диапазон)

**Словарные (12):**
- evolving landscape, vibrant, tapestry, fostering, innovative, delving, cultivating, pivotal moment, intricate interplay, crucial, harnessing, transformative, dynamic, showcases, enduring

**Атмосферные (2):**
- tapestry (метафора ткачества)
- journey (метафора путешествия)

**Содержательные (4):**
- vibrant (рекламный язык)
- dynamic environment (пустая абстракция)
- transformative potential (преувеличение)
- enduring commitment (пустая риторика)

**Итого:** 20 маркеров на 121 слово = **95% вероятность AI**

### Ожидаемый результат редактуры

```
Remote work has created both opportunities and challenges for companies and employees. Technology enables connections, but maintaining human relationships remains important. Companies are exploring new collaboration tools and flexible arrangements to keep teams productive while supporting work-life balance.

The shift from traditional offices to distributed teams has changed how we approach work. Understanding the relationship between technology and human needs is essential for making remote work successful. Organizations continue to adapt to this increasingly digital workplace.
```

**Результат:** 0 маркеров, смысл сохранён.

## Как использовать эти тексты

### Для тестирования Rule

```
1. Создайте файл articles/test-D1.md с текстом D.1
2. Запустите: @ai-text-detector
3. Сравните результат с ожидаемым анализом
4. Повторите для D.2-D.7
```

**Критерий успеха:** Rule находит 90%+ маркеров из анализа.

### Для тестирования Skill

```
1. Скопируйте текст D.1
2. Запустите: /ai-text-editor edit
3. Сравните результат с ожидаемой редактурой
4. Проверьте сохранение смысла
5. Повторите для остальных текстов
```

**Критерий успеха:** Skill удаляет 90%+ маркеров, смысл сохранён.

### Для тестирования Subagent

```
1. Возьмите ИСХОДНЫЙ и ОТРЕДАКТИРОВАННЫЙ тексты
2. Запустите: /ai-text-verifier
3. Subagent должен найти пропущенные маркеры (если есть)
4. Проверить сохранение смысла
5. Дать вердикт PASS/NEEDS REVISION/FAIL
```

**Критерий успеха:** Subagent находит пропущенные маркеры, объективно оценивает.

### Для тестирования полного workflow

```
1. Возьмите текст D.1
2. Rule → анализ (находит ~20 маркеров)
3. Skill → редактирование (убирает маркеры)
4. Subagent → верификация (PASS или NEEDS REVISION)
5. Если NEEDS REVISION → повторить Skill
6. Финал: текст готов к публикации
```

**Критерий успеха:** Полный цикл за 2-3 минуты, результат PASS.

## Создание своих тестовых текстов

### Генерация текстов с маркерами

Используйте ChatGPT/Claude БЕЗ промпта-ограничителя:

```
Write a 100-word article about [topic].
Use sophisticated, professional language.
```

**Результат:** Текст с 60-80% маркеров.

### Генерация текстов с минимумом маркеров

Используйте промпт из Приложения B:

```
Write a 100-word article about [topic].

AVOID: tapestry, delve, pivotal, showcase, intricate, foster, crucial
AVOID: "not X—it's Y" construction
Use simple, direct language.
```

**Результат:** Текст с 10-20% маркеров.

### Генерация естественных текстов

Напишите сами или возьмите из:
- Личных блогов (не профессиональных)
- Комментариев на форумах
- Неотредактированных постов в соцсетях
- Инструкций/рецептов

**Результат:** Текст с 0-10% маркеров.

## Расширенная коллекция (бонус)

Для более глубокого тестирования создайте тексты:

**По жанрам:**
- Новостная статья
- Блог-пост
- Бизнес-презентация
- Академическая статья
- Креативное письмо (фантастика)
- Техническая документация
- Маркетинговый текст

**По концентрации маркеров:**
- 0-10% (естественный)
- 20-40% (лёгкое касание AI)
- 50-70% (средняя зараженность)
- 80-100% (сильная зараженность)

**Edge cases:**
- Текст с одним типом маркеров (только структурные)
- Текст со всеми типами маркеров равномерно
- Текст с техническими терминами (false positives)
- Текст на русском языке
