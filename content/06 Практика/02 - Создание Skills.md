# Создание Cursor Skills для редактирования AI-текста

## Что такое Skill

**Cursor Skill** — это папка с файлом `SKILL.md` в `.cursor/skills/`, который активируется по требованию и выполняет специализированные задачи с использованием процедурных инструкций.

**Применение для AI-текста:** Skill работает как активный редактор, который анализирует и исправляет текст, удаляя AI-маркеры при сохранении смысла.

---

## Разница между Rule и Skill

| Характеристика | Rule | Skill |
|----------------|------|-------|
| **Триггер** | Автоматический (при открытии файла) | По требованию (пользователь вызывает) |
| **Функция** | Пассивный (обнаруживает) | Активный (редактирует) |
| **Размер** | Короткий (~50-100 строк) | Длинный (до 5000 токенов) |
| **Workflow** | Одношаговый (анализ) | Многошаговый (анализ → редактирование → верификация) |
| **Контекст** | Основной контекст | Progressive disclosure (загружается при необходимости) |

---

## Структура Skill для AI-редактора

### Frontmatter (обязательный)

```yaml
---
name: ai-text-editor
description: "Анализирует и редактирует AI-генерированные тексты, удаляя характерные маркеры при сохранении смысла и авторского голоса. Используй когда пользователь просит проверить текст на AI-маркеры, отредактировать AI-текст или выполнить постобработку."
---
```

**Параметры:**
- `name`: уникальное имя навыка
- `description`: детальное описание + условия автоактивации

### Основные разделы

**## Overview** (2-3 параграфа)
- Что делает Skill
- Когда использовать
- Какие проблемы решает

**## Features**
- 3 режима работы (analyze, edit, verify)
- Сохранение исходного смысла
- Детальный отчёт об изменениях

**## Usage**
Инструкции для каждого режима с примерами

**## Guidelines**
Правила работы (10-15 пунктов)

**## Keywords for Auto-Activation**
Фразы-триггеры для автоматической активации

**## Examples**
2-3 конкретных примера использования

## Три режима работы Skill

### Режим 1: Analyze (только анализ)

**Цель:** Детальный анализ без редактирования

**Chain-of-Thought процесс:**
```
1. SCAN: Прочитай текст полностью
2. COUNT: Подсчитай маркеры по категориям
3. RANK: Найди топ-5 самых явных
4. SCORE: Вычисли вероятность AI (0-100%)
5. REPORT: Выведи структурированный отчёт
```

**Формат вывода:**
```markdown
## 📊 AI-АНАЛИЗ ТЕКСТА

### Статистика по категориям
[детальный подсчёт]

### 🔥 Топ-5 самых явных маркеров
[список с цитатами]

### 🎯 Оценка вероятности AI: [%]
[обоснование]

### 💡 Рекомендация
[что делать дальше]
```

### Режим 2: Edit (редактирование)

**Цель:** Удаление AI-маркеров с сохранением смысла

**Chain-of-Thought процесс:**
```
1. ANALYZE FIRST: Запусти анализ
2. PRESERVE: Определи, что НЕ трогать
3. EDIT: Редактируй по категориям
4. VERIFY: Проверь качество правок
5. DOCUMENT: Запиши все изменения
```

**Few-shot примеры:**

**Пример 1: Слова-маркеры**
```
❌ Было: "The innovative startup ecosystem has evolved into a vibrant tapestry of creativity"
✅ Стало: "The startup ecosystem combines creativity and entrepreneurship"

Изменения:
- Убрал "innovative" (AI-маркер)
- Убрал "vibrant tapestry" (метафора-клише)
- Упростил "evolved into" → простое "combines"
```

**Пример 2: Структурные паттерны**
```
❌ Было: "This is not just about technology—it's about fostering human connections"
✅ Стало: "Technology enables human connections, but connections remain the priority"

Изменения:
- Убрал конструкцию "не X — это Y" с тире
- Убрал "fostering" (AI-глагол)
- Прямое утверждение вместо противопоставления
```

**Пример 3: Атмосферные клише**
```
❌ Было: "In the quiet hum of our digital era, a ghostly echo whispers"
✅ Стало: "In our digital era, a new voice emerges"

Изменения:
- Убрал "quiet" (атмосферное клише)
- Убрал "ghostly echo whispers" (накопление AI-метафор)
- Простое, прямое утверждение
```

### Режим 3: Verify (верификация)

**Цель:** Проверка качества после редактирования

**Chain-of-Thought процесс:**
```
1. COMPARE: Сравни оригинал и редакцию
2. SCAN: Проверь на новые проблемы
3. SCORE: Оцени улучшение
4. RECOMMEND: Дай финальные рекомендации
```

**Формат вывода:**
```markdown
## ✅ ВЕРИФИКАЦИЯ

### Качество редактирования
- Смысл сохранён: [✅ Да / ❌ Нет]
- Естественность: [оценка]
- Читаемость: [1-10]

### Сравнение AI-вероятности
- До: [%]
- После: [%]
- Улучшение: [%]

### 🎯 Финальная рекомендация
[Готово / Требуется доработка]
```

## Guidelines для Skill

### Принципы редактирования

1. **ВСЕГДА начинай с режима Analyze** — понимание полной картины критично
2. **Сохраняй исходный смысл** — редактируется только стиль, не содержание
3. **Используй простоту** — замена сложных конструкций простыми
4. **Убирай украшательства** — метафоры без смысла должны уходить
5. **Проверяй контекст** — не все маркеры нужно удалять

### Что НЕ делать

6. **НЕ удаляй технические термины** — если "tapestry" описывает реальный гобелен, оставь
7. **НЕ меняй авторский голос** — если автор намеренно использует сложный стиль, адаптируй
8. **НЕ упрощай до примитива** — цель не "детский язык", а естественное письмо
9. **НЕ редактируй цитаты** — прямая речь остаётся как есть
10. **НЕ трогай имена собственные** — даже если "Elara Voss" — AI-клише

### Формат отчётов

11. **Структурируй отчёты** — используй заголовки, списки, эмодзи
12. **Документируй каждое изменение** — "Было → Стало → Причина"
13. **Обосновывай решения** — почему конкретная правка улучшает текст
14. **Давай статистику** — количество правок по категориям
15. **Финальная рекомендация** — чёткий вывод о готовности текста

## Расширение Skill: Новые режимы

### Режим Conservative (минимальная редактура)

```markdown
### Режим 4: Conservative

**Принцип:** Убирай только самые явные маркеры

**Правила:**
- Удаляй только топ-маркеры (delve, tapestry, pivotal)
- Оставляй спорные случаи
- Максимум сохранения исходного текста
- Минимум вмешательства в стиль

**Когда использовать:** Текст хорошего качества, но с редкими AI-следами
```

### Режим Aggressive (максимальная очистка)

```markdown
### Режим 5: Aggressive

**Принцип:** Удаляй все потенциальные маркеры

**Правила:**
- Убирай даже спорные конструкции
- Любые тире → замена на другую пунктуацию
- Все метафоры → конкретные описания
- Фокус на полное удаление AI-следов

**Когда использовать:** Текст сильно "заражён" маркерами (>80%)
```

### Режим Style-Match (сохранение стиля)

```markdown
### Режим 6: Style-Match

**Принцип:** Редактируй маркеры, но сохраняй авторский стиль

**Процесс:**
1. Анализируй авторский стиль в других текстах
2. Определи характерные фразы и конструкции
3. Редактируй только явные AI-маркеры
4. Сохраняй стилистику автора

**Когда использовать:** Автор имеет узнаваемый стиль
```

## Автоактивация Skill

### Keywords для автоматического запуска

```markdown
## Keywords for Auto-Activation

- "проверь текст на AI"
- "убери AI-маркеры"
- "отредактируй AI-текст"
- "постобработка AI"
- "сделай текст человечнее"
- "удали AI-паттерны"
- "очисти текст от AI"
- "humanize AI text"
- "remove AI markers"
```
