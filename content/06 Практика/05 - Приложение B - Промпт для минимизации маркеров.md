# Приложение B: Шаблон промпта для минимизации AI-маркеров

Используйте этот промпт при генерации текста через AI, чтобы минимизировать характерные маркеры.

---

## Универсальный шаблон

```
[ВАША ОСНОВНАЯ ИНСТРУКЦИЯ]

---

STYLE GUIDELINES:

Use direct, clear language.

AVOID these words and phrases:
- tapestry, delve, pivotal, showcase (verb), intricate
- foster, crucial, landscape (as metaphor), vibrant, testament
- underscore (verb), highlight (verb), garner, enhance
- align with, enduring, interplay, meticulous, swift, adept

AVOID these constructions:
- "It's not X, it's Y" with em dashes (—)
- Grouping everything in threes (tricolons)
- "No X. No Y. Only Z." format
- "X with Y and Z" for sarcasm
- Making everything "quiet", "ghostly", or "whispered"
- Weaving/textile metaphors ("woven into", "fabric of")
- Turning everything into a "journey"
- Using "serves as" / "marks" instead of "is/are"
- False ranges "from... to..." without a real scale

FOCUS ON:
- Concrete facts and specific examples
- Simple, direct statements
- Natural language with appropriate repetition
- Genuine sensory details (only when relevant and accurate)
- Being specific rather than gesturing at "broader significance"

AVOID promotional language:
- "nestled in", "breathtaking", "boasts"
- Exaggerating significance with "pivotal moment", "testament"

DON'T give abstract concepts physical properties:
- No tastes, smells, or textures for emotions or concepts
- Use sensory language only for actual physical objects
```

## Примеры использования

### Пример 1: Генерация статьи о технологиях

```
Напиши статью о remote work на 500 слов.

---

STYLE GUIDELINES:

Use direct, clear language.

AVOID: tapestry, delve, pivotal, showcase, intricate, foster, crucial, landscape (metaphor), vibrant, testament, underscore, highlight, garner, enhance, align with

AVOID constructions:
- "It's not X, it's Y" with em dashes
- Tricolons (grouping by three)
- "serves as" instead of "is"
- False ranges "from... to..."

FOCUS ON:
- Concrete examples from real companies
- Simple statements
- Natural repetition
- Specific data and facts

---

ADDITIONAL REQUIREMENTS:
- Include 2 real company examples
- Cite specific statistics
- Use active voice
- Keep sentences under 25 words
```

### Пример 2: Генерация креативного текста

```
Напиши короткий рассказ о художнике (500 слов).

---

STYLE GUIDELINES:

Use natural, vivid language without AI clichés.

AVOID atmospheric clichés:
- Don't make everything "quiet", "ghostly", or "spectral"
- Avoid "whisper", "echo", "shadow" as metaphors
- Don't describe everything as "woven" or a "tapestry"
- Avoid journey metaphors ("embarking on", "navigating")

AVOID character names:
- Elara Voss, Elena Voss, Kael, Echo

FOCUS ON:
- Genuine sensory details from real experience
- Concrete actions and objects
- Natural dialogue
- Specific, unique details

Use "is/are" naturally, don't replace with "serves as".
Avoid grouping everything in threes.
```

### Пример 3: Академическое письмо

```
Напиши abstract для научной статьи о machine learning (200 слов).

---

STYLE GUIDELINES:

Use precise, technical language without AI markers.

AVOID:
- "delve into", "explore", "investigate" → use specific verbs
- "intricate", "complex" → be specific about what makes it complex
- "pivotal", "crucial", "key" → use "important" or be specific
- "serves as", "represents" → use "is"
- "Additionally", "Furthermore" at sentence start → use "Also" or rewrite

FOCUS ON:
- Specific methods and results
- Quantitative data
- Clear contributions
- Direct statements

Use passive voice only when necessary.
Cite specific prior work, not "researchers argue".
```

## Специализированные промпты

### Для блога

```
STYLE: Conversational but not overly enthusiastic

AVOID:
- "And you know what?" type rhetorical questions
- Everything being a "journey"
- Overusing em dashes for "not X—it's Y"

FOCUS:
- Personal anecdotes
- Practical tips
- Conversational tone without AI quirks
```

### Для бизнес-контента

```
STYLE: Professional but not promotional

AVOID:
- "nestled in", "breathtaking", "boasts"
- "pivotal moment", "testament to"
- "vibrant", "dynamic", "innovative" (overused)
- "align with", "foster", "cultivate" (corporate speak)

FOCUS:
- Concrete benefits
- Specific data
- Clear value propositions
- Direct language
```

### Для креативного письма

```
STYLE: Literary but grounded in real experience

AVOID:
- Everything being "quiet" or "ghostly"
- "woven into fabric" metaphors
- Giving abstractions physical properties
- Character names: Elara/Elena Voss, Kael

FOCUS:
- Genuine sensory details
- Specific objects and actions
- Natural dialogue
- Unique observations
```

## Тестирование промпта

### Процедура проверки

1. Сгенерируйте текст с промптом
2. Запустите через Rule (`@ai-text-detector`)
3. Если маркеров > 10 → улучшите промпт
4. Если маркеров < 5 → промпт работает хорошо

### Итеративное улучшение

**Итерация 1:** Базовый промпт
```
AVOID: tapestry, delve, pivotal
```

**Результат:** Найдено 15 маркеров

**Итерация 2:** Расширенный список
```
AVOID: tapestry, delve, pivotal, showcase, intricate, foster, crucial, landscape (metaphor), vibrant, testament
```

**Результат:** Найдено 8 маркеров

**Итерация 3:** Добавлены конструкции
```
AVOID слова + конструкции:
- "not X—it's Y"
- tricolons
- "serves as"
```

**Результат:** Найдено 3 маркера ✓

## Дополнительные стратегии

### Использование примеров

Добавьте few-shot примеры в промпт:

```
GOOD EXAMPLE:
"The startup ecosystem combines creativity and entrepreneurship."

BAD EXAMPLE:
"The startup ecosystem has evolved into a vibrant tapestry of creativity and entrepreneurship."

Write like the GOOD example.
```

### Явные инструкции по повторам

```
REPETITION GUIDELINE:
It's okay to repeat key terms. Don't force synonyms.

GOOD: "The artists created art. The artists worked together."
BAD: "The artists created art. The creative individuals worked together."
```

### Указание конкретики

```
BE SPECIFIC:
Instead of: "the evolving landscape of technology"
Write: "new developments in cloud computing"

Instead of: "a pivotal moment"
Write: "an important change" or "a turning point"
```

## Когда промпт не помогает

### Проблема: AI игнорирует инструкции

**Решение:**
1. Разделите на этапы (сначала генерация, потом постобработка)
2. Используйте Skill для редактирования
3. Попробуйте другую модель

### Проблема: Маркеры всё равно появляются

**Решение:**
1. Усильте формулировки ("NEVER use", "STRICTLY avoid")
2. Добавьте примеры (few-shot)
3. Используйте постобработку (Rule + Skill + Subagent)

### Проблема: Текст становится слишком простым

**Решение:**
1. Добавьте: "Use sophisticated language, but avoid AI clichés"
2. Дайте примеры хорошего стиля
3. Укажите баланс: "Clear but not simplistic"

## Сохранение промпта

### Создайте библиотеку промптов

```
.cursor/
  prompts/
    base-style-guide.md           ← базовый шаблон
    blog-style-guide.md           ← для блогов
    business-style-guide.md       ← для бизнеса
    creative-style-guide.md       ← для креатива
    academic-style-guide.md       ← для академии
```

### Используйте как reference

В Rule или Skill:

```markdown
## Style Guidelines

См. `.cursor/prompts/base-style-guide.md` для полного списка
```
